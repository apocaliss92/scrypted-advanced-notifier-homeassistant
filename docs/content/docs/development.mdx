## Version management

```bash
npm run version:patch   # bump patch + sync to manifest.json
npm run version:minor
npm run version:major
npm run version:sync    # sync VERSION → manifest.json without bumping
```

`VERSION` is the source of truth. `scripts/sync-version.js` writes it into
`custom_components/scrypted_an/manifest.json` and `package.json`. Always keep
these three in sync.

## CI pipeline (`.github/workflows/release.yml`)

Triggers on every push to `main`:

1. **Hassfest** — validates manifest format and structure
2. **HACS validation** — validates HACS compatibility
3. **Release** — bumps patch version, commits, tags `vX.Y.Z`, creates GitHub Release

## Docs pipeline (`.github/workflows/docs-deploy.yml`)

A separate workflow. It runs the docs **drift guard** first, then builds the
Next.js site, then deploys it to Railway once the Railway variables exist. It
never touches `VERSION`, tags or releases — see [Hosting](/docs/hosting).

Its path filter deliberately includes `custom_components/**`: a code change can
change the generated reference, so a code change must be able to redeploy the
docs — and must fail the guard if the generated pages were not regenerated.

## Keeping the docs honest

```bash
npm run docs:generate   # rewrite the generated reference pages from the source
npm run docs:check      # fail if they drift, or if a page cites something gone
npm run docs:dev        # local dev server on http://localhost:3000
npm run docs:build      # production build
```

Two guards, both run in CI:

- `scripts/docs_generate.py --check` regenerates every DO-NOT-EDIT page in memory
  and diffs it against what is committed. Editing a generated page by hand, or
  changing the code without regenerating, fails here.
- `scripts/docs_check_refs.py` walks every MDX page and verifies that each repo
  path, SCREAMING_SNAKE constant, scrypted_an_ identifier, Scrypted class name
  and internal link it names still resolves in the source tree.

The rule behind both: **anything derivable from the repository is generated;
anything else is prose whose every citation is checked.**

## Language

All code comments, docstrings, commit messages, and PR descriptions must be in
**English**.
