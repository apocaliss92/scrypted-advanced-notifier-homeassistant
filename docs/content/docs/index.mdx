Custom integration for [Home Assistant](https://www.home-assistant.io/) that
connects to the [Scrypted Advanced Notifier](https://github.com/apocaliss92/scrypted-advanced-notifier)
plugin.

These pages are a **view** over this repository. Nothing is authored here that is
not also in the repo — `README.md` stays the file HACS renders, and the code stays
the source of truth for behaviour.

## What it does

- Automatic entity discovery from Scrypted cameras
- Real-time state updates pushed from the plugin into the Home Assistant event bus
- Several entity platforms — the authoritative list is
  [Entity platforms](/docs/reference/entities), generated from the code
- Commands sent back to Scrypted via REST

## How this site stays current

Everything that can be read out of the repository is **generated** into
[Reference](/docs/reference) by `scripts/docs_generate.py`, and a CI check
(`scripts/docs_check_refs.py` plus `docs_generate.py --check`) fails the build
when a generated page drifts from the source or when a page names a file,
constant or class that no longer exists. Prose pages are hand-written; the facts
under them are not.
