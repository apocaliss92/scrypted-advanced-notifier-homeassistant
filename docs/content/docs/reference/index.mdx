## Why generate at all

A page a human retypes is a page that goes stale the first time someone forgets.
The generator parses the real Python with the standard library `ast` module and
reads the real JSON — it never regexes prose, and it never invents a value that is
not in the tree. What cannot be derived stays prose, and
`scripts/docs_check_refs.py` checks that the prose still names things that exist.
