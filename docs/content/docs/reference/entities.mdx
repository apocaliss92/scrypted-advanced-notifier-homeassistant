## Component-config keys

The plugin sends each entity an MQTT-autodiscovery-shaped `cmps` payload. These are the keys the integration actually reads out of it.

### Read by every entity

| Key |
| --- |
| `enabled_by_default` |
| `entity_category` |
| `icon` |
| `name` |
| `stat_t` |
| `state_topic` |

| Platform | Additional keys |

| `binary_sensor` | `dev_cla`, `device_class` |
| `sensor` | `dev_cla`, `device_class`, `stat_cla`, `state_class`, `suggested_display_precision`, `unit_of_meas`, `unit_of_measurement` |

| `select` | `cmd_t`, `command_topic`, `options` |
| `image` | `image_topic` |
| `camera` | `rtsp_url`, `stream_source` |
