## Push endpoint (served by Home Assistant)

`ScryptedPushView` in `push_view.py`. Authentication is a bearer token compared against the configured HA Secret, not Home Assistant's own auth.

| Attribute | Value |
| --- | --- |
| `name` | `api:scrypted_an:push` |
| `requires_auth` | no |
| `url` | `/api/scrypted_an/push` |


Accepted `type` values in the POST body:

| Message type |
| --- |
| `state_update` |
| `rotate_secret` |
| `entity_change` |
| `batch` |
| `heartbeat` |
